# E-ORG-002: organisation In your own cloud

The platform's operator asked `admin orgs delete` for an organisation that has a server or a
resource In your own cloud, in the customer's AWS account. The platform cannot remove what it made
In your own cloud yet, so it deletes only organisations that are Hosted by us. The message names the
server or the resource. Nothing changed: the organisation stays active and its apps keep running.

**Fix:** leave the organisation as it is: an organisation In your own cloud cannot be deleted yet
