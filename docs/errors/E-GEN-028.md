# E-GEN-028: script URL

A URL attribute starts with the `javascript:` or `vbscript:` scheme, written out or followed by a
`{{ }}`, or an SVG animation sets such a URL. The browser runs the rest of the URL as script.
Spaces, tabs, newlines and character references in the scheme do not hide it.

**Fix:** link to a page, or attach behaviour in index.ts
