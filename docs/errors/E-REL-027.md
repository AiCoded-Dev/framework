# E-REL-027: you are not an approver of this app type

Each app type names the group of people who approve its approval cards, as `approvers`; a type
that names none is approved by the organisation's security admins. You are not in that group,
through the organisation's group map, so you cannot approve or decline the card. The message names
the group. Nothing was released, and the card still waits for an approver. See
[app types](../guides/app-types.md).

**Fix:** ask someone in the group the message names to approve the card, or ask your security admin to add you to that group
